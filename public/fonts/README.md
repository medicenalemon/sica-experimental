# DejaVu Sans

Archivos originales sin modificar de DejaVu Sans y DejaVu Sans Bold, distribuidos por Debian (`fonts-dejavu-core`). Se usan para las constancias internas PDF y conservan sus nombres originales. La licencia y los avisos de Bitstream Vera se incluyen en `LICENSE-DejaVu.txt`. Las modificaciones de DejaVu son de dominio público. Estos archivos no cambian la autoría ni la licencia del código de SICA.
